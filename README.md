# Persoonlijke agentic OS

Een Obsidian-vault die ik met Claude Code gebruik voor werk en privé: urenregistratie,
terugkerende taken, lijsten en kennis. Zie `CLAUDE.md` voor structuur en conventies.

Setup: kopieer `.env.example` naar `.env` en vul de sleutels in. Indexen bouwen met
`python3 scripts/build_index.py` (draait ook automatisch via hooks).
